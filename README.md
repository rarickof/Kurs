Lab 02 - Классы, агрегация и композиция. Язык программирования с ручным управлением памятью

Проект состоит из файлов main.cpp, Guest.cpp, Hotel.cpp и Room.cpp, а также заголовочных файлов/

Описание проекта:
Класс Hotel владеет массивом объектов Room. Номера не могут существовать без отеля. При уничтожении отеля номера уничтожаются автоматически.
Агрегация (Использование):
Класс Room хранит указатель на заселенного гостя (Guest*). Номер использует гостя, но не управляет его временем жизни (при выселении или уничтожении номера гость продолжает существовать).

Инкапсуляция и Инварианты:
Все поля скрыты (private). Объекты самостоятельно следят за корректностью своего состояния. Реализованы запрет на заселение в занятый номер, запрет на создание номера с ценой <= 0).

Демонстрация времени жизни:
В main.cpp организован вложенный блок { ... }, показывающий разницу в вызове деструкторов для композиционных и агрегационных связей.

При использовании VS 2026:
Открыть решение (.sln) или папку с проектом в Visual Studio.
Убедится, что кодировка консоли поддерживает кириллицу (в коде уже вызывается std::setlocale(LC_ALL, "Russian");).
Запустить проект без отладки (Ctrl + F5), чтобы консольное окно не закрылось сразу после завершения программы и вы успели увидеть порядок вызова деструкторов.
